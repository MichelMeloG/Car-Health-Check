# Avisos de terceiros

## obd-diagnostic-app

Este projeto usa como referência arquitetural o repositório [jasmine-erkel/obd-diagnostic-app](https://github.com/jasmine-erkel/obd-diagnostic-app), acessado em setembro de 2026. O repositório é licenciado sob MIT.

A integração OBD do Car Health foi reimplementada para a arquitetura Expo/TypeScript deste projeto. A referência influenciou a escolha de BLE/ELM327, a sequência de inicialização e o conjunto inicial de PIDs.

## react-native-ble-plx

O acesso BLE utiliza a biblioteca `react-native-ble-plx`, conforme sua licença e avisos distribuídos pelo pacote.
